# 教材质量、核验边界与审校交接

## 这套内容是什么

课程按输入包的 86 个单元编排，分 Pre-A1、A1、A2、B1、B2、C1、C2 七个入口。课序由本项目设计：先用声音和短任务建立联系，再逐步整理格、动词、复句与篇章；CEFR用来描述能力方向，不被当成官方逐课语法表。完成课程、选择题正确或录过音，都不自动等于达到某一CEFR级别。

课文、练习、通知、邮件、人物对话及交易数字为原创教学材料。案例中的房租、报价、公交线路、取件要求、预约条件、公共通知均不是实时事实，不能脱离课堂用于现实办事。外部参考只核验语言规则、词形与能力框架；不打包整本商业教材，不复制外部长篇课文或受限媒体。

## 已完成的质量控制

- 每课有独立捷语正文与中文理解、目标、先修、规律与适用边界、易错点、词汇变形与例句、听力脚本、发音练习、主动输出、答案依据、迁移及复习链接。
- 声音入口把长短元音和重音分开，说明c/č、r/ř、h/ch、di/ti/ni、ě组合与清浊同化；不以中文谐音长期替代捷语声音。
- 基础语法把“结构规则”和“场景意思”分开：位置/方向、未完成体/完成体、自己的/他人的、必须/不必/禁止、寄出/送达、缺件/损坏分别设对照。
- 开放口语、写作、互动和转述提供样例、解析与量规；样例不是唯一正确答案，不用精确假分替代人工判断。听读选择题只证明相应题型表现。
- 每个单元有新情境检查，每级有六种能力的综合任务；未见材料与示范任务有区分，级别测评包含补课路径。
- 来源与核验状态写在各课及 `content/sources/`。该目录中的记录区分成功访问、失败访问、内部复核和未进行的母语审校。

## 自动审计能证明什么

运行：

```text
node scripts/validate-content.mjs --verify-media-hashes
```

默认只读检查全部课程，输出 `evidence/content-validation.json` 与 `evidence/content-coverage.csv`。它会检查 JSON结构、稳定ID、版本、单元数、先修/复习/补课链接、依赖环、课文非空、封闭题答案、开放题量规、词汇字段、完整课文重复、实际题型和技能分布、知识点到题目及测评的直接映射。媒体存在时，检查捷语标识、文件路径、句段定位、媒体版本，并可校验文件SHA256。

`passed_structure_checks` 只表示上述结构检查没有错误，不表示全套语言已获母语认可。报告中的warnings必须阅读：媒体缺失、映射缺口或篇幅提示不能靠更名隐藏。`--levels Pre-A1,A1,A2` 是部分审计，报告会显示 `partial_selected_levels`，不得拿它当全课程通过证据。

内部篇幅目标为A1每课至少80个捷语词、A2至少140、B1至少220、B2至少300、C1至少450、C2至少550；这是控制正文深度的编辑约束，不是欧洲委员会的达标规定。字数达标也不能证明自然度、观点复杂性或听力难度达标。Pre-A1以声音、单词和短句序列计，不为凑字数强塞难文。

## 当前语言审校状态

所有原创课文保留“未逐句母语审校”状态。已实际核对的官方规则包括捷语元音、辅音位置、连贯语音、i/y、数词格形、条件式、物主词适用边界及部分名词表；具体范围以各来源记录为准。未成功打开的词条不能写成已经查核。其余原创材料做了内部一致性检查，但这与独立母语审稿不是同一层证据。

基础三阶段实有 32 课、324 道课内练习、32 个单元检查与3个级别测评，共122道测评题；其部分审计见 `content/sources/foundation-content-report.json`。最终全套数量与媒体实有/缺失数以交付时完整运行得到的 `evidence/content-validation.json` 为准，不用编写时间较早的部分报告覆盖最终结果。

C1/C2尤其需要继续核验自然语域、隐含意义、反讽边界、长篇论证和题目可区分性。具有复杂词汇和足够长度不自动意味着高阶材料合格；商业发布前应让捷语母语教学者独立抽检并逐课记录修改，不把所有高阶课无条件标“审核通过”。

## 音频与发音证据

录音文件、TTS可用性、句级重播和慢速播放属于媒体及产品层证据。合成音频文件真实存在，不等于已由母语者完整听检。Piper等合成语音的正常/慢速素材应与生成脚本、ID、文本版本及SHA256对应；若某条没生成，清单必须显示缺失，页面只在检测到捷语语音时使用回退。

口型和发音位置图是教学示意，不是医学解剖诊断；ASR转写相同不等于音素标准。对比回听、明确的长短音或辅音观察及用户自评可以保存为证据，但不能制造“发音准确率98%”一类无校准数字。

## 最短审校路线

1. 先运行完整只读审计，解决结构错误与直接映射缺口；抽查音频文本版本，避免内容改了但旧音频仍被标为对应版本。
2. 每级抽一课，独立完成一项封闭题和一项主动输出，核对样例、解析与迁移任务是否一致；重点抽查七格、数词、指代、体和礼貌语域。
3. 母语审校按“原句—问题类别—修改—原因—审核者—日期”留存；以新内容版本发布，保留旧版本及旧作答可追溯。
4. C1/C2再由另一位审校者检查长文难度、论证和语用，听完正常/慢速音频的异常候选项。未进行的审校继续保留未完成状态。

本文件不替代需求状态表；它解释哪些证据支持什么结论，以及哪些语言质量结论仍不能下。
