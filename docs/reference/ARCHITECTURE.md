# 系统结构与实现边界

本工程是一个可独立运行的个人捷语学习应用。Node 24 同源服务读取独立 JSON 教材，SQLite 保存账号和学习证据，浏览器在用户主动下载后保留离线课文与音频。运行应用不需要 npm 安装，不依赖付费 API，也没有嵌入外部网页或模拟服务器。

## 代码分工

| 文件 | 实际职责 |
|---|---|
| `app/server/main.mjs` | HTTP、同源与主机校验、认证路由、资源与 Range 响应、录音上传、教材更新、备份入口 |
| `config.mjs` | 可移动根目录、端口保留规则、回环监听、显式数据目录与可选 HTTPS 源 |
| `auth.mjs` | scrypt 密码、随机会话与 CSRF、HttpOnly Cookie、恢复码 |
| `db.mjs`、`app/migrations/001.sql` | SQLite STRICT 表、外键、WAL、迁移和事务 |
| `content.mjs` | 教材导入与不可改写版本、练习快照、课程地图和真实统计 |
| `events.mjs` | 事件去重、服务器评分、证据分离、乱序复习重算、可解释推荐 |
| `backup.mjs` | SQLite 在线一致性快照、所有历史教材、录音与媒体清单、独立恢复 |
| `ai.mjs` | 可选 HTTPS API 适配、调用状态与真实 token/配置价格记录 |
| `app/public/app.js` | 8 个工作页面、课堂、测评、词汇、迁移、设置与内容管理 |
| `storage.js`、`sync.js` | IndexedDB 队列、用户独立 Cache、重试与逐项确认 |
| `audio.js`、`sw.js` | 真实课程文件、句级切片与重复、录音、离线应用壳与下载资源 |

## 一次回答如何成为证据

浏览器先生成 UUID，将用户、设备、课程版本、题目、回答和 UTC 时间写入 IndexedDB。服务器从该课程历史快照读取题型、能力和评分依据，不采信客户端声称的分数。一个事务中保存不可变原事件和能力证据。只有服务器逐项接受后，浏览器才从待同步队列删除该项。

`UNIQUE(user_id,event_id)` 与规范化请求哈希共同保证重试幂等。相同 ID 和内容返回原结果；相同 ID、不同内容返回 409 并保留原记录。两设备的不同事件是追加关系，没有整份进度覆盖。复习队列从 `occurred_at,event_id` 排序重建，因此旧离线事件不会以“最后收到”为由覆盖新表现。游标按服务器单调 `seq` 拉取，日期显示和独立完成日期按用户时区派生。

选择题记录识别证据，填空/排序/改错在未看提示时可记录主动输入证据。写作、口语、互动和转述保存回答、参考表达与量规，自动分数为 null。用户自评另存事件，不升级成系统自动认定的能力。每题可关联多个知识点，能力页明确展示其分母是知识点证据数。连续不同日期的独立记录只标“有跨日独立证据”，不折算为 CEFR 证书或精确掌握率。

## 教材与版本

基础课、单元检查和级别测评各用稳定 ID。每课 JSON 可单独修改，但已导入的 `(id,version)` 不允许内容变动；必须提高版本。数据库保留所有历史正文与练习快照，旧设备迟到的回答仍按当时版本评分。新版的文件导入 `content/updates/`，新安装时可重新加载。正式发布后不要直接改已有版本文件，也不要清除旧音频。

音频独立存储；元数据包含完整轨道、段落、句级正常/慢速起止时间及 SHA256。多个句级引用共用实际文件，下载与备份会去重。慢速文件独立合成，播放率为 1；不以失真变速冒充真人自然快语速。

## 离线与账户生命周期

应用壳可以缓存；私有课程只在用户点击下载后缓存。Service Worker 不缓存登录、账号、进度、导出等敏感响应。学习进度另有最近同步的 IndexedDB 副本用于离线显示，明确是本机状态。录音 Blob 也先入队，联网后先上传录音再提交相关事件。每项失败保留原文，显示错误。

退出会清除所有本应用私有缓存、草稿与队列；有未同步内容时先明确告知。离线退出另保留一个撤销标记，联网后撤销旧服务器会话。不同浏览器同一账号可有独立会话；本期只创建一个私人账号，不实现多租户。修改密码、恢复密码会撤销全部旧会话。

## 持久化与备份

SQLite 使用 `node:sqlite backup()` 得到一致性快照，而不是复制仍在写入的主库。根据快照引用复制不可变录音，附带历史教材及正常/慢速媒体，并对全部文件作 SHA256 清单。快照删除会话，保留账号哈希与学习记录；恢复后需重新登录。恢复必须是独立空目录，验证完整性与外键后才允许 Windows 脚本切换配置，旧目录继续保留。

本地备份是明文文件，具有账号哈希、学习记录和录音；应用不声称提供磁盘加密。保护这些文件由部署目录权限与用户的备份存储方式决定。

## 已知实施取舍

- 使用原生模块和零运行时依赖，免前端构建；测试浏览器依赖单独锁定。
- 面向个人使用，进度目前按用户全量派生；超大多年事件库需要再做分页/索引性能评估。本轮测试没有做百万事件容量承诺。
- 通用 AI 文字反馈接口已实现，默认关闭；没有真实供应商密钥联调，也未加入自动语音识别或音素评分。
- 高阶材料为原创模拟新闻、讨论与论述，合成音频为单一捷语声线；真人多声线、自然快语速与逐句母语审校仍待完成。
