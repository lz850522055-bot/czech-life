# Contributing

Help make a language feel like a place to live. This alpha needs real playtesting and focused improvements more than a larger feature list.

1. Choose an issue or propose a major direction before writing a large rewrite.
2. Fork, create a branch and follow [setup](docs/GETTING_STARTED.md).
3. Make one focused change with reproducible verification.
4. Open a PR. Maintainers review and decide whether to merge.

Gameplay/UI: actual captures and device/browser. Performance: repeatable route and before/after frame times. Czech: original/proposed wording, explanation and a source/native review context. Geography: source/date/transform/license/attribution.

`npm test` is asset-free; full art/audio checks need the release pack. Do not publish user DBs, recordings, tokens, passwords, cache, local config or private conversations. Preserve map/audio/vendor licenses. Label AI-generated and simulated material honestly; no fabricated benchmarks or educational results.

Original code/content contributions use MIT unless a specific third-party license applies. CC BY-SA recording/transcript adaptations remain BY-SA. Public Git history starts with this baseline and records commits, not every editor change. Be respectful and focus criticism on reproducible behavior.
