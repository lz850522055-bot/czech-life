# Security

Do not post credentials, setup/recovery tokens, learner recordings or databases in issues. Use private vulnerability reporting when enabled. If no private channel is available, report only the type/existence of the concern without exploit details or personal data.

This is an early local-first prototype, not a hardened multi-tenant service. Bind to loopback, configure an exact HTTPS origin for deliberate remote access, and back up private progress before testing changes. Do not expose your learner instance as an anonymous demo.
