# 捷语人生 · Czech Life

**游戏里真正过关，现实里真正会用。** [English](README.md)

《捷语人生》是一款**以学习捷语为第一目标的人生模拟游戏**。最大的目标是：玩家在游戏中真正通过A1、A2，乃至C2的能力关卡，现实中的捷语能力也能对应到那个等级。游戏里的成长，要变成现实里的能力；通关不靠刷经验，而靠真正听得懂、说得出、读得明白、写得清楚，并能应对没背过的新情境。

为了实现这一点，我们希望从布拉格开始，一比一重建捷克生活的训练环境：真实街道、路段、建筑、公共设施、景点和社区，让你像身在当地一样生活。真实地图、人文和商业环境都是为了让语言学习发生在真实需求中。

你可以模拟租房、买菜、乘车、交朋友、处理误会、阅读通知、开店和经营。开店以后要面对客户、供应商、进货、库存、租金、人工、水电和成本；经营情境以有来源、有日期的捷克政策与当地资料构建。你学会的捷语，要支撑你把这些事真的处理明白。

**最终追求：让游戏里的你，与现实生活中的你，在语言能力和应对当地生活的能力上同步成长，逐步具备独立生活、工作和融入捷克的能力。** 之后再扩展更多捷克地区和多人互动。

这是项目要实现并验证的目标，当前仍是早期原型，尚未验证“游戏通关等于现实CEFR等级”。[完整目标与通关标准](docs/VISION.md)

## 下载运行

安装Node.js 24+、Git，确保系统有tar。

```sh
git clone https://github.com/lz850522055-bot/czech-life.git
cd czech-life
npm run assets:fetch
npm start
```

首次运行资源约下载1.01GB，解压约1.13GB，验证SHA-256后安装。不需要买域名或开通付费API。打开终端给出的本机网址，用本机显示的初始化口令创建账号，再进入 `/game/?district=small-town`。没有公开默认密码。
