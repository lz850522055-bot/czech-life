## 必须处理的路网语义

道路类别以 streets.metadata.json 的 typkomunik codedValues 为准：其中 25=消失路段、34=施工中，不能加入已开放行走图；机动车专用、公路、独立轨道、园区内部、隧道和不明通行属性还需进一步筛选。来源的 usek_naz 是路段端点/区间描述，不能直接当成标准街道名称。smerovost 是来源交通方向字段，不能简单套成步行方向。

路段几何交叉不能自动等同平面连通，桥上/桥下与隧道须单独判定；未知连接不能靠直线补齐。需要补充完整的步行拓扑、建筑占地与街名来源后，才能作为角色连续寻路世界交付。
